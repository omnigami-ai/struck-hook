# Music

`song.mp3` is this skill's song: an instrumental in bold, bright electro-pop at 120 BPM, made for this skill by omnigami with AI. `song-stems/` holds its stems (`drums.m4a`, `rest.m4a`), split from it with Demucs.
`node scripts/render.mjs film --audio music/song.mp3` fits it to the film: it starts on a bar line and, near the end, the drums land one hit and stop while the rest closes and fades. `--from <seconds>` starts at another section.
Usage terms: see the skill's licence.
